# SRM Casablanca-Settat: Predictive Maintenance for Power Transformers

## 📌 Project Overview
This project focuses on transitioning from reactive maintenance to a proactive Industry 4.0 strategy for High/Medium Voltage (HTA/MT) substations. The core objective was optimizing the maintenance of the On-Load Tap Changer (OLTC), the most solicited component in power transformers.

## ⚙️ Technical Approach & Methodology

* **Reliability Analysis:** Conducted historical data studies using Pareto and MTBF (Mean Time Between Failures) to pinpoint critical failure modes.
* **Automated Fault Detection:** Designed a PLC logic framework that cross-references sensor signals to classify faults instantaneously.
* **Active Prevention & Thermal Modeling:**
    * Implemented an "adaptive deadband" algorithm to protect equipment from network instabilities.
    * Integrated the **IEC 60076-7** mathematical thermal model to accurately anticipate overheating and extend equipment lifespan.

## 🛠️ Tools & Technologies
* PLC Automation
* IEC 60076-7 Standards
* Reliability Engineering (Pareto, MTBF)
